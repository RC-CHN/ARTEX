# Worker 预算、撤除登记与记录导出

## Worker 的 150＋10

默认每个 Worker 意图可执行 150 轮，之后追加明确的预算通知并进入最多 10 轮收尾：保存事实、证据路径、部署登记和未完成事项，最后以纯文本汇报。最后一轮会再次提示直接汇报；用完后保留已有记录并结束执行。收尾阶段 Bash 在执行层禁用，包括通过 ExecuteExtraTool 间接调用；记录、读取和汇报工具仍可用。

预算按意图持久累计，模型迭代前事务预留；并发预留不会突破上限，进程中断不退还可能已经执行的轮次。暂停、重试、上下文压缩和服务重启不重置额度。输出恢复迭代计入轮数，底层网络重试和压缩模型调用不单独计轮。这是执行轮数限制，不是费用或累计 token 硬上限。

新安装使用 150＋10；升级时一次性把旧 Worker 的 0 默认迁移为 150＋10，已有正数自定义值保留。迁移之后再明确设置 0 表示不限常规轮数。旧意图从升级后首次执行建立账本，不追溯历史轮数。修改默认配置只影响尚未建立账本的意图。

Worker 用 `get_worker_budget` 查自己的预算，需要追加时调用 `ask_main_agent` 说明进度、证据和具体所需轮数。主 Agent 用 `grant_worker_budget` 提交原意图 ID、刚读到的 revision、追加值、理由和稳定 request_id；人类可在任务“记录与收尾”操作。相同参数重试不重复追加，过期版本返回冲突及重新读取提示。Worker 自己调用会被拒绝。追加不自动重跑或解除暂停，已停止的 Worker 从原会话继续；已经进入收尾的当前执行仍完成收尾，下次执行使用新额度。Planner 不应以重复意图绕过预算。

## 独立资源与任务部署

`resource-creator` 默认 Skill 要求按可独立使用、更新和撤除的单位登记资源。同一工具的说明和多架构文件可组成一个资源；不同位置的临时进程、代理、文件等分别登记在任务部署清单，不消耗任务的资源选择额度。

- `manage_deployments`：list/get/save，save 可批量传入 items；记录位置、准确标识、撤除方法、状态与验证。更新需要 expected_revision；保存和批量每项需要稳定 request_id。
- `resource_references`：查询资源的任务引用及部署。
- `delete_resource`：删除资源登记，阻止新使用，保留历史版本和证据。其他活动任务引用、尚未撤除的部署会阻止删除；Agent 当前任务自己的固定版本不阻止删除。
- `manage_resources_batch`：最多 25 个独立操作，逐项提交，成功项不回滚；回执列出 succeeded/failed 和逐项结果。
- `check_task_handoff`：列出待撤除、明确保留、运行或未完成 Worker、待处理主 Agent 问答。检查只覆盖已登记信息，不证明所有外部部署都已发现。

改登记和删除资源都不会执行远端命令。标为 removed 或 retained 必须提供实际验证或保留依据；结果未知不能标为成功。删除资源是保留历史的逻辑删除，不会释放已发布版本占用的配额。部署账本在任务冷归档后仍保留，避免未撤除部署失去引用保护。

## 完整记录资料包

任务“记录与收尾”可异步生成、查看进度、取消、重试和下载；任务列表可精确选择最多 20 个任务。Agent 的 `export_task_records` 只允许当前任务，不会自动扩大到关联任务或全局流量。它仅生成副本，不负责撰写渗透测试报告。

包内包括实际留存的任务与探索记录、会话和工具输入输出、模型记录与用量、任务文件、选中或任务创建的资源版本、部署与预算历史，以及绑定发现的 HTTP 证据。提供 JSONL、会话 Markdown、离线 HTML 和 manifest.json；后者记录每个文件的大小、SHA-256、快照时间及缺失原因。下载显示整包 SHA-256，支持 HTTP Range 续传。

数据库使用同一个只读可重复读快照。运行中的任务不会暂停；文件复制仅针对快照时可用内容，跳过符号链接、特殊文件和检测到的并发变更，并记入缺失清单。它不是冻结整个文件系统的原子快照：文件与数据库可能存在时间差，包内明确说明。

未录制的模型请求、已经清理的文件不能恢复。全局历史代理流量没有可靠任务归属，因此只导出已明确绑定的流量证据，不按域名猜测并混入其他任务。部署只关联资源 ID、没有固定版本时，资料包保留资源描述与部署登记，不猜测其实际部署版本。凭据库密文不导出；原始任务记录和文件仍可能含秘密。

可另生成“过滤常见凭据字段”副本：结构化 JSON（含嵌套 JSON 字符串）保持有效格式，常见凭据字段和认证头被替换，二进制和超过 8 MiB 的文本附件排除并记录原因。该过滤不保证识别任意格式秘密，外发前需审阅；原始记录不修改。

生成任务持久排队，租约与每次执行的唯一 owner 防止旧进程提交结果。取消最多等待当前 I/O 或下一次心跳检查（5 秒）；进程重启后过期租约可重新生成。默认最多 10 个排队/生成任务、单包 20 GiB/20 万文件、已完成包合计 100 GiB、保留 7 天。重试也受队列限制；取消和删除导出副本都不改变原始任务。临时孤立文件按所有权和保留时间回收。

## 验证

本次新增测试使用临时 PostgreSQL 和合成任务，不需要读取生产任务内容。覆盖实际 150＋10 轮、并发预留、追加权限/CAS/重放、资源删除阻塞与历史保留、部署并发写入、多个任务的同一数据库快照、导出校验/续传/跨任务隔离/路径边界/凭据过滤，以及真实浏览器里的登记、验证撤除、追加预算、下载与删除资源流程。`ci/lifecycle-ui-smoke.cjs` 作为发布镜像检查运行。
