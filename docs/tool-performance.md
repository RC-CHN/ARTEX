# 工具执行成本与恢复边界

## 工具原语

工具的搜索顺序、匹配规则、分页计数、输出格式和权限判定继续沿用已有接口。性能优化不缓存文件内容、网络响应或资源最新版本，以免把陈旧数据交给 Agent。

| 路径 | 处理方式 |
| --- | --- |
| Read | 按页流式读取，返回版本及字节游标；后续页可直接 seek，避免从文件头重新扫描。分页提示经过 Runner、Harness 两层输出限制后仍保留，不复制一份源文件到输出区。 |
| Write / Edit / MultiEdit | 同目录暂存后原子替换；跨进程侧边锁串行化协作工具写入，可选 `expected_version` 拒绝过期修改。编辑读取按已知大小分配，避免反复扩容和整块复制。 |
| Grep | ripgrep 边读边保留请求页，同时统计完整结果数；Go 回退的非内容计数按行扫描，多行匹配单向推进，合并有序上下文区间。多行/内容回退仍需读取完整文件。 |
| Glob / LS | Glob 每次目录遍历只拆解一次模式；LS 复用 ReadDir 的排序，仅分两遍输出目录和文件。仍返回完整的原有顺序。 |
| Bash | 同步路径流式保留头尾，超过限制时直接落完整输出文件；输出目录失败时使用原有头尾截断格式。后台路径已在磁盘上记录输出，TaskOutput 从尾部读取。 |
| Shell | 复用滑动窗口的底层缓冲，保留绝对游标、遗漏提示和屏幕模拟语义；滚动历史仍保留 256 KiB，复用缓冲最多 512 KiB。 |
| WebFetch | 复用 HTTP 客户端；HTML 解析直接读取响应字节，去掉中间字符串复制。请求、代理回退、提取规则和超时不变。 |
| 通用调用链 | 单文本结果直接引用，聚合文本一次分配；摘要分块计算。工具列表直接遍历索引，解锁列表在复制后释放读锁再排序。 |

定时等待、交互等待、网络服务耗时与外部进程本身的计算时间不通过减少等待、跳过检查或改变重试规则来“优化”。资源发布与文件同步的版本检查、事务和完整性校验继续保留。

## 文件与错误反馈

Read 默认 2,000 行，最多 10,000 行；单行显示最多 2,000 字节，单次扫描最多 64 MiB。深页使用同一返回结果中的 `offset`、`byte_offset`、`expected_version`；版本变化时重新读取。Edit / MultiEdit 的整文件处理上限为 64 MiB，更大的文件使用流式脚本，输出到当前执行的持久工作目录。版本是包含文件身份及修改时间的元数据修订号，不是全文哈希。

协作工具使用 `.artex-lock-*` 稳定侧边锁，不能在仍有执行者时删除；`.artex-write-*` 是临时提交文件，失败时清理。新文件遵守 umask，已有文件保留权限位。原子替换会更换 inode，不能用于依赖原 inode、硬链接、特殊文件或额外 ACL/xattr 保留的操作；这些操作应使用相应文件系统工具。共享存储需支持原生文件锁；不参与锁协议的外部 Shell 写入无法获得同等事务保证，提交前版本检查只能检测已发生的冲突。

可处理的文件错误返回 `code`、`executed`、`retryable`、`next_action`，使模型知道如何修正。当前文件错误中的 `executed=false` 表示目标更新未提交。连续相同工具、相同参数及相同错误达到 3 次时提示调整方法，6 次时提示使用可用的 `ask_main_agent` 询问一次并继续独立工作；不自动重复有副作用的调用，也不因此终止任务。参数变化或成功会重置该工具的连续失败计数。

## Runner 与模型调用

纯续租仅保存变化的节点时间和会话租约元数据，不重新编码历史命令结果。元数据、诊断状态和 checkpoint revision 在同一 PostgreSQL 事务中提交；取消、写入失败或 CAS 冲突不发布待提交租约。内存回滚保留最近成功续租的时间覆盖层，防止退回更早的完整检查点。新操作指标为 `checkpoint_metadata`。

启动、结果接收、通知、过期与其他状态变更仍使用完整状态编码加片段增量写入。元数据过大或存储没有快路径时回退原路径；这不是对所有检查点操作的零复制改造。保留写入总时限、进度超时及最早已提交租约的安全余量。

关闭模型录制时不复制请求体。录制写库最多等待 3 秒，轻量计量最多等待 1 秒，保持同步写入以避免异步任务与删除流程的竞态。稳定系统提示始终设置缓存断点；模板输出的本轮时间放到动态尾段，真实时间仍可见。依赖时间条件分支的自定义模板仍可能改变稳定正文。

## 验证

本轮只使用合成文件和本机临时 PostgreSQL；没有读取集群任务内容。基准、原始数据及复现命令见 [工具原语基准](../benchmarks/tool-primitives.md)。回归覆盖跨进程并发编辑、取消、版本冲突、权限与符号链接、分页等价性、输出落盘失败、PTY 游标、检查点事务回滚和数据库锁等待；并在关键包执行 Go race 检测。
